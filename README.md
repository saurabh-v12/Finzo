## 🚀 What is Finzo?

Finzo is an intelligent personal finance tracker that automatically extracts, categorizes, and analyzes your financial transactions from uploaded bank statements — no manual entry required.

---

## ✨ What Makes Finzo Unique

- **One Upload, Full Picture** — Upload any PDF bank statement and Finzo instantly extracts all transactions, detects recurring payments, and builds a complete financial profile automatically.
- 
**Behavioral AI Insights** — Powered by Google Gemini, Finzo doesn't just show numbers — it analyzes spending patterns, detects hidden costs, and gives personalized advice with real rupee amounts.
- 
**Dynamic Risk Scoring** — A live financial risk score calculated from 5 real factors: debt-to-income ratio, payment consistency, savings rate, spending volatility, and investment discipline.

## 📦 Installation

```bash
# Clone the repo
git clone https://github.com/saurabh-v12/Finzo
cd Finzo

# Create virtual environment
python -m venv venv
venv\Scripts\activate  # Windows

# Install dependencies
pip install -r backend/requirements.txt

# Add your API keys
cp .env.example .env
# Edit .env and add your GEMINI_API_KEY

# Run the backend
uvicorn backend.main:app --reload

# Open frontend
# Visit http://localhost:8000
```

## 📸 Features

- 📄 **Document Upload** — PDF, JPG, PNG, CSV bank statements
